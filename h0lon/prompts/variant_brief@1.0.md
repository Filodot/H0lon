# Задача: краткий конспект — только главное

В `inputs/master.md` — полный мастер-конспект темы. Сделай из него **краткий конспект на 2–4 страницы A4**: то, что нужно помнить по теме, без подробностей.

- По каждой главе мастера: ключевые определения (дословно по смыслу, но коротко), главные теоремы и формулы (без доказательств), 1–3 тезиса о том, когда и зачем это применяется.
- В конце — **карта связей**: маркированный список «понятие → на чём основано → что из него следует».
- Формулы — точно как в мастере, LaTeX (`$…$`, `$$…$$`). Обозначения не меняй.
- Только то, что есть в мастере. Ничего не добавляй.
- Оформление: заголовки `#` по главам, короткие списки, блоки `::: {.definition title="…"}` и `::: {.theorem title="…"}` только для самого главного. Без якорей `[[…]]`, комментариев `<!-- … -->` и приложений мастера.
- Язык — русский, английские термины в скобках, как в мастере.

Запиши результат в `out/variant.md`, начиная с первого заголовка (титульную часть добавит программа). Других файлов не пиши.
