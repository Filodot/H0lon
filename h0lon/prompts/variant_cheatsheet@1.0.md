# Задача: шпаргалка на 1–2 листа A4

В `inputs/master.md` — полный мастер-конспект темы. Сделай **шпаргалку**: максимально плотную сводку формул, определений и условий применимости, которую можно распечатать на 1–2 листах A4 мелким шрифтом.

- Структура — по главам мастера, заголовки `#` и `##` короткие.
- Каждая строка — один факт: формула с одной строкой пояснения обозначений и условий («при $p \ge 1$», «если ядро финитно»). Определения — одной строкой.
- Таблицы — для сравнений (методы, ядра, метрики: формула, свойства, когда применять).
- Никаких доказательств, примеров, мотивации и повторов. Формулы — точно как в мастере, LaTeX.
- Только то, что есть в мастере. Без якорей `[[…]]`, комментариев `<!-- … -->` и приложений мастера.
- Язык — русский.

Запиши результат в `out/variant.md`, начиная с первого заголовка (титульную часть добавит программа). Других файлов не пиши.
