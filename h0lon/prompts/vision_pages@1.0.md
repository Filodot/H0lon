# Задача: точная транскрипция страниц в Markdown

Тебе даны изображения страниц одного учебного источника (PNG в `inputs/`). Для каждой страницы есть файл `inputs/p<NNNN>.txt` с текстовым слоем PDF — он может быть пустым, неполным или искажённым (особенно в формулах). Для каждой страницы запиши ровно один файл `out/p<NNNN>.md` — полную транскрипцию этой страницы.

## Главное правило

Это транскрипция, а не конспект. Переносится всё содержательное, что есть на странице, в исходном порядке и исходной формулировке. Ничего не сокращай, не пересказывай, не обобщай, не исправляй и не дополняй от себя. Если на странице есть ошибка, перенеси её как есть: исправления делает следующий этап.

## Что и как переносить

- **Текст** — дословно, на языке оригинала. Абзацы — как в источнике; переносы слов внутри строки склеивай.
- **Заголовки** разделов и подразделов — заголовками Markdown `###` и ниже (уровни `#` и `##` заняты служебными заголовками; не добавляй заголовок страницы).
- **Формулы** — LaTeX: строчные `$…$`, выключные `$$…$$` на отдельных строках; многострочные выкладки — `$$\begin{aligned} … \end{aligned}$$` с выравниванием по знакам равенства. Переписывай формулу символ за символом: индексы, степени, штрихи, знаки, пределы сумм и интегралов, жирные и ажурные буквы (`\mathbf`, `\mathbb`, `\mathcal`). Текстовый слой подсказывает написание, но при расхождении верь изображению.
- **Семантические блоки** — fenced divs, только если блок явно обозначен в источнике словом, рамкой или выделением («Определение», «Теорема», «Лемма», «Утверждение», «Следствие», «Доказательство», «Пример», «Задача», «Решение», «Замечание», «Def.», «Thm.», «Proof»):

  ```
  ::: {.definition title="Случайная величина"}
  Текст определения.
  :::
  ```

  Классы: `definition`, `theorem`, `lemma`, `proposition`, `corollary`, `proof`, `example`, `problem`, `solution`, `remark`. Атрибут `title` — только если у блока в источнике есть название. Не придумывай блоки там, где их нет.
- **Списки** — маркированные и нумерованные списки Markdown с исходной вложенностью.
- **Таблицы** — pipe-таблицы; объединённые ячейки повтори или опиши в ячейке словами.
- **Рисунки, графики, схемы, диаграммы** — словесное описание, достаточное, чтобы понять содержание без картинки: что изображено, подписи, оси и их значения, стрелки и связи, выделенные элементы. Формат:

  ```
  ::: {.figure-description}
  График функции распределения: ступенчатая функция со скачками в точках 1, 2, 3, 4 …
  :::
  ```

  Подпись к рисунку из источника перенеси дословно первой строкой описания.
- **Код** — блоком кода с указанием языка, дословно.
- **Неразборчивое** — `[неразборчиво]` на месте фрагмента. Сомнительное чтение — вариант и пометка `[?]` сразу после него. Не угадывай.

## Что не переносить

Колонтитулы, номера страниц, логотипы, водяные знаки, служебные строки шаблона презентации (название курса, имя лектора, дата в каждом слайде), навигационные элементы. Если служебная информация встречается один раз и содержательна (например, список литературы), — переноси.

## Формат файла

Файл `out/p<NNNN>.md` начинается сразу с содержимого страницы, без заголовка с номером страницы и без пояснений от тебя. Пустая по содержанию страница (только колонтитулы или декоративная обложка) — одна строка `<!-- пустая страница -->`. Не пиши никаких других файлов.

## Вариант: document

Страницы документа: методичка, учебник, статья, конспект. Текст обычно идёт сплошными абзацами; формулы нумеруются — номер формулы перенеси через `\tag{…}`.

## Вариант: slides

Страницы — слайды презентации. Заголовок слайда уже есть в служебном заголовке — не повторяй его. Пункты слайда переноси списком с исходной вложенностью. Анимационные повторы (слайд, дополняющий предыдущий) переноси полностью: дедупликацию сделает следующий этап. Схемы и графики на слайдах описывай подробно — часто в них основное содержание.

## Вариант: scan

Страницы — сканы или фотографии (печатный текст или рукопись). Текстового слоя обычно нет. Учитывай наклон, тени и шум. Для рукописи: стрелки, скобки, выделения цветом и отступы — смысловые связи, передавай их структурой (списки, блоки) или кратким пояснением в квадратных скобках. Пометки автора «?», «??», «?!» рядом с текстом сохраняй как есть.
