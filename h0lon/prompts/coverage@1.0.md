# Задача: решить судьбу непокрытых блоков

Мастер-конспект должен содержать всю информацию из источников. Автоматическая проверка нашла блоки источников (`inputs/uncovered.md`), на которые в мастере нет ссылки. Для каждого блока реши, что с ним:

- `duplicate` — его содержание уже полностью есть в мастере (укажи, где: id раздела `sec:…` и что именно повторяет);
- `admin` — служебное или организационное: даты, дедлайны, объявления, титульный слайд, оглавление источника, колонтитул, пустой блок;
- `missing` — содержательный блок, которого в мастере нет или есть не полностью (укажи раздел, куда его следует добавить, — id из `inputs/outline.md`).

Сомневаешься между `duplicate` и `missing` — выбирай `missing`: лишнее добавление дешевле потерянного факта.

Запиши `out/coverage.json`:

```json
{"verdicts": [
  {"block": "S1.b031", "verdict": "missing", "section": "s02-01",
   "note": "условие сходимости из слайда 24 нигде не приведено"},
  {"block": "S1.b001", "verdict": "admin", "section": null, "note": "титульный слайд"},
  {"block": "P2.b044", "verdict": "duplicate", "section": "s01-02",
   "note": "то же определение метрики, что в S1.b020"}
]}
```

Вердикт нужен для каждого блока из входа. Других файлов не пиши.
