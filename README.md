# H0lon

**H0lon** собирает из всех материалов по учебной теме — рукописных конспектов, PDF, презентаций, видео- и аудиолекций — один максимально полный мастер-конспект в PDF, а из него по промпту делает вариации: краткую выжимку, учебный конспект с интуицией и примерами, шпаргалку, перевёрстку под другой шаблон.

> *H0lon turns every source you have for a university topic (handwritten notes, PDFs, slides, recorded lectures) into one complete, source-linked master summary as a PDF, then derives variants (brief, study guide, cheat sheet, re-templated) from it. Russian-first; built on headless Claude Code / Codex runs so a subscription is enough, no API spend. Status: early development (milestone M0: scaffolding, PDF rendering, agent runner). Windows 11 first; macOS and Linux are best effort.*

Холон — целое, которое одновременно является частью большего целого: конспект темы — целое и часть курса, источник — целое и часть конспекта.

## Статус

Принят [PRD v1.0](docs/PRD.md). Готовы этапы **M0 — каркас** (конфигурация и CLI, проверка окружения, рабочие области тем, рендер Markdown → PDF, раннер headless-агентов) и **M1 — текстовые источники** (приём PDF, слайдов, DOCX, Markdown, TeX и веб-страниц и их извлечение в Source Docs с распознаванием формульных страниц агентом). Синтез мастер-конспекта из Source Docs — следующий этап M2. Публичного релиза ещё не было, формат конфига и команд может меняться — изменения записываются в [CHANGELOG](CHANGELOG.md).

## Быстрый старт

Нужны Windows 11, [uv](https://docs.astral.sh/uv/), Git, MiKTeX и хотя бы один агент — Claude Code (подписка Pro/Max) или Codex CLI (вход через ChatGPT). Пошаговая установка с нуля — в [docs/INSTALL.md](docs/INSTALL.md).

```powershell
git clone https://github.com/Filodot/H0lon.git
cd H0lon
uv sync
uv run h0lon init
uv run h0lon doctor
uv run h0lon render tests/fixtures/sample_master.md
uv run h0lon agent-test
```

`doctor` покажет, чего не хватает, и подскажет команды установки; `render` соберёт тестовый PDF; `agent-test` проверит, что агент запускается в headless-режиме и пишет результат.

## Что умеет сейчас (M0–M1)

| Команда | Что делает |
|---|---|
| `h0lon init` | Создаёт `h0lon.toml` из примера, каталог рабочих областей и каталог служебных данных |
| `h0lon doctor` | Проверяет `claude`, `codex` и вход в них, Pandoc, XeLaTeX и пакеты шаблона, шрифты, ffmpeg, yt-dlp, CUDA; для отсутствующего — команды установки |
| `h0lon new "<тема>" --course <курс>` | Создаёт рабочую область темы (ASCII-слаг, `topic.yaml`, стандартные папки, git-репозиторий) |
| `h0lon render <файл.md>` | Pandoc → XeLaTeX с A4-шаблоном: кириллица, формулы, окружения определений и теорем, оглавление, закладки. При неудаче — запасной путь HTML → PDF через Edge/Chrome |
| `h0lon add <тема> <файлы и ссылки>` | Добавляет источники в тему: копия в `sources/`, хэш, автоопределение вида (PDF, скан, слайды, DOCX, Markdown, TeX, веб, видео, аудио, фото), сигналы качества |
| `h0lon sources <тема>` | Показывает источники темы и статус извлечения |
| `h0lon extract <тема>` | Извлекает источники в Source Docs (`extracted/<ID>/source.md`, `blocks.jsonl`, `summary.md`): текст — кодом, страницы с формулами, сканы и графику — агентом; `--dry-run` показывает план прогонов |
| `h0lon agent-test` | Создаёт задание (TaskBundle), запускает `claude -p` или `codex exec`, проверяет файлы результата, повторяет с обратной связью и переключается на запасной агент, пишет `run.json` и журнал расхода токенов |

Подробности по каждой команде — `uv run h0lon <команда> --help`.

## Как это будет работать

```
источники ─► извлечение (код, локальные модели, короткие прогоны агентов)
          ─► Source Docs (Markdown + LaTeX + якоря на страницы/слайды/таймкоды)
          ─► [проверка пользователем]
          ─► синтез одной сильной моделью: структура → разделы → глобальная правка
          ─► проверка полноты по карте покрытия ─► Pandoc → XeLaTeX → PDF
          ─► вариации из мастера
```

Ключевые свойства:

- **Полнота проверяется**: каждый блок источника имеет id, синтез обязан его процитировать, непокрытые блоки дорабатываются отдельным проходом.
- **Прослеживаемость**: каждый абзац мастера ссылается на страницу, слайд или таймкод.
- **Честные правки**: однозначные описки исправляются и попадают в журнал правок; расхождения между источниками и редакторские дополнения вынесены в приложения.
- **Дёшево парсим, дорого синтезируем**: извлечение делается детерминированным кодом и локальными моделями, а понимание — одной моделью с полным контекстом темы.
- **Подписка вместо API**: LLM-работа выполняется headless-прогонами Claude Code (`claude -p`) и Codex CLI (`codex exec`); API через proxyapi запланирован как дополнительный бэкенд.

## Подписки, приватность, учётные данные

Версия 1 требует подписку Claude Code и/или ChatGPT для Codex: агенты запускаются их штатными headless-режимами `claude -p` и `codex exec`. Вход выполняется в самих CLI; H0lon не хранит и не передаёт логины, пароли и токены. Материалы тем отправляются в Anthropic или OpenAI так же, как при обычной работе с этими агентами. Рабочие области, `h0lon.toml`, логи и прогоны лежат вне репозитория.
