# Решения, принятые автономно

Владелец разрешил вести разработку без остановок (2026-10-04) и отложить на потом всё, что требует его анализа. Здесь — решения, которые приняты по умолчанию и которые стоит просмотреть. Каждое легко изменить; где нужно — указано, что именно поменять.

| № | Дата | Решение | Почему так | Как изменить |
|---|---|---|---|---|
| A1 | 2026-10-04 | Расход недельного лимита подписки на разработку — не выше 50 % (указание владельца); новые волны агентов запускаются только после проверки `rate_limit_event` | беречь лимит на учёбу владельца | — |
| A2 | 2026-10-04 | Исполнители кода M2+ работают на Claude Sonnet, синтез мастера — на Opus (уровень `strong`) | Sonnet вдвое дешевле, качество кода проверяет интеграция и тесты; Opus выбран владельцем для синтеза | `agents.claude.model_strong` в `h0lon.toml` |
| A3 | 2026-10-04 | Review gate в CLI: `h0lon build` останавливается с кодом 3 и подсказкой, одобрение — `h0lon approve <тема>`; одобрение сбрасывается при изменении извлечения | PRD D10 требует видимый выключатель; в CLI это флаг `--no-review` | ARCHITECTURE «Review gate и команды» |
| A4 | 2026-10-04 | Группы S2 — по 1–4 раздела, до ~60 000 символов блоков на группу, параллельно до `agents.parallel_runs` (2) | баланс контекста модели, числа прогонов и лимита | `synth/sections.py` |
| A5 | 2026-10-04 | Если глобальная правка S3 дважды теряет ссылки на блоки — остаются разделы S2 без глобальной правки, с предупреждением | лучше без общей нотации, чем с потерей материала | `synth/globalpass.py` |
| A6 | 2026-10-04 | Глоссарий — ненумерованный раздел после основного текста и перед приложениями; введение — ненумерованный раздел в начале | PRD 5.4 не задаёт место глоссария | `synth/assemble.py` |
| A7 | 2026-10-04 | После успешной сборки — коммит в git-репозиторий темы | PRD D13: «каждая сборка — коммит» | `general.git_per_topic = false` |
