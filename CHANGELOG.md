# Журнал изменений

Все заметные изменения проекта записываются в этот файл.

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [семантическое версионирование](https://semver.org/lang/ru/). Версии промптов указываются в именах файлов (`h0lon/prompts/<имя>@<версия>.md`) и меняются при любом изменении текста.

## [Unreleased]

Этап M0 — каркас. Первый релиз будет `0.1.0`.

### Добавлено

- PRD v1.0 (`docs/PRD.md`) с решениями D1–D16 и описание модулей и контрактов (`docs/ARCHITECTURE.md`).
- Пакет `h0lon` на Python 3.11+ с окружением через `uv`, линтером `ruff` и тестами `pytest` (маркеры `needs_xelatex`, `needs_browser`, `live_agent`).
- Конфигурация `h0lon.toml`: пример `h0lon.example.toml`, поиск файла (`--config` → `H0LON_CONFIG` → `./h0lon.toml` → каталог пользователя), переопределение любого ключа переменной `H0LON_<РАЗДЕЛ>__<КЛЮЧ>`.
- CLI `h0lon`: команды `version`, `init`, `doctor`, `new`, `render`, `agent-test`.
- `h0lon init` — создание `h0lon.toml`, каталога рабочих областей и каталога служебных данных.
- `h0lon doctor` — проверка агентов и входа в них, Pandoc, XeLaTeX и пакетов шаблона, шрифтов, ffmpeg, yt-dlp, CUDA с командами установки; вывод в JSON (`--json`).
- `h0lon new` — рабочая область темы: ASCII-слаг из русского названия, `topic.yaml`, стандартные папки, git-репозиторий на тему.
- Рендер `h0lon render`: Pandoc → XeLaTeX с A4-шаблоном `a4-notes` и Lua-фильтрами, многопроходная компиляция, проверка PDF, запасной рендер HTML → PDF через Edge/Chrome, удаление якорей источников (`--clean`), пользовательские шаблоны в `<state_dir>/templates/`.
- Раннер headless-агентов: TaskBundle (`runs/<id>/`), бэкенды Claude Code (`claude -p`) и Codex CLI (`codex exec`), проверка результата (файлы, заголовки, JSON Schema), повторы с обратной связью, переключение на запасной агент и «остывание» при лимитах, `run.json` и журнал расхода `usage.jsonl`; команда `h0lon agent-test`.
- Загрузка окон подписки Claude (5 часов, 7 дней) из события `rate_limit_event`: пишется в `run.json` и `usage.jsonl`, показывается в сводке `agent-test`; при загрузке от 80 % — предупреждение.
- Досрочная остановка Claude при ошибке входа или исчерпанном окне лимита, без ожидания внутренних повторов CLI.
- Этап M1 — текстовые источники:
  - `h0lon add` — приём файлов и ссылок: копия в `sources/` с ASCII-именем, sha256, автоопределение вида (PDF-текст, скан, слайды, DOCX, Markdown, TeX, веб, видео, аудио, фото), профиль PDF и сигналы качества, скачивание веб-страниц, раскрытие шаблонов `*`/`?`, защита от дубликатов; `h0lon sources` — таблица источников темы.
  - `h0lon extract` — Source Docs (`extracted/<ID>/source.md`, `blocks.jsonl`, `summary.md`): разбиение на блоки через AST Pandoc с якорями мест, кэш по ключу, `--dry-run` с планом прогонов, `--no-vision`, `--force`.
  - PDF и слайды: классификация страниц (текст, формулы, скан, графика), чистка колонтитулов и разреженного текста, распознавание формульных страниц, сканов и графики агентом батчами с текстовым слоем как подсказкой и кэшем страниц; PPTX через python-pptx (заметки докладчика, таблицы, картинки).
  - DOCX, Markdown, TeX (макросы, окружения теорем) и веб-страницы (trafilatura) — без агента.
  - Промпты `vision_pages@1.0` (транскрипция страниц) и `summary@1.0` (аннотация, оглавление, термины).
- Этап M2 — синтез мастер-конспекта: `h0lon build` (структура темы, разделы параллельными группами, глобальная правка нотации и повторов, проверка полноты по блокам с дополнением пропущенного, сборка `master.md` с введением, глоссарием и приложениями А–Г, рендер с автопочинкой LaTeX и запасным HTML-движком, коммит в git темы), `h0lon approve` (review gate), `h0lon status`; кэш стадий, `--from`, `--force`; защита от потерь — проверка ссылок на блоки после каждой стадии; правка файлов агентом «на месте» (затравка `out/`); промпты `outline`, `sections`, `globalpass`, `coverage`, `supplement`, `fixlatex`.
- Рендер: кириллица внутри формул и символы, которых нет в текстовом шрифте (⟨⟩, ⇒, ℝ …), набираются корректно; удалённые картинки становятся ссылками; формулы без `$` в приложениях не ломают XeLaTeX.
- Этап M3 — локальный веб-интерфейс `h0lon serve`: темы, загрузка файлов и ссылок, переключатель review gate, задачи с живым журналом (SSE), экран проверки Source Docs (страницы и текст с MathML), мастер в браузере, страница проверки окружения; строгая CSP, защита от межсайтовых запросов и выхода за каталог темы.
- Этап M4 — рукописные конспекты: фото и PDF-сканы с `--kind handwritten`, подготовка страниц (поворот, обрезка, усиленная копия), распознавание на сильном уровне по правилам дословной транскрипции (`handwritten_pages@1.1`), вопросы автора и служебные пометки отдельными блоками.
- Этап M7, часть 1 — вариации мастера: `h0lon variant` (кратко, учебный конспект, шпаргалка в компактном шаблоне `a4-compact`, свой запрос, перевёрстка другим шаблоном), `h0lon variants`, блок «Вариации» в веб-интерфейсе, пометка «устарело» при изменении мастера.
- Общие слои: запуск процессов в UTF-8 с таймаутом и завершением дерева процессов, очистка окружения от переменных родительской сессии Claude Code; поиск Pandoc (включая `pypandoc-binary`), XeLaTeX (MiKTeX, TeX Live), браузеров и нативного `codex.exe` для npm-установки.
- CI на GitHub Actions: `ruff check` и `ruff format --check`, `pytest` на Windows и Ubuntu с Python 3.11 и 3.13.
- Документация: README, установка на чистую Windows 11 (`docs/INSTALL.md`), адаптация под себя (`docs/ADAPT.md`), этот журнал; нормализация концов строк в `.gitattributes`.
